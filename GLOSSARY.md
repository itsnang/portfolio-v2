# Portfolio

The personal portfolio of Lorn Samnang: public pages about their work and writing, plus a private area for editing that content.

## Language

### Sites

**Site**:
One independently deployed part of the portfolio, reachable at its own domain or subdomain.
_Avoid_: App, micro frontend, zone

**Main Site**:
The Site at the root domain, presenting the profile, projects and achievements.
_Avoid_: Web, home app, portfolio site

**Blog Site**:
The Site where visitors read published Posts.
_Avoid_: Blog (when the deployed thing is meant)

**Admin Site**:
The private Site where the owner signs in and edits all portfolio content.
_Avoid_: Dashboard, CMS, back office

### Content

**Blog**:
The content domain of Posts, which the Blog Site presents and the Admin Site edits.
_Avoid_: Using it to mean the Blog Site

**Post**:
A single written article belonging to the Blog.
_Avoid_: Article, entry

### Code organisation

**Shared Package**:
Code used by more than one Site.
_Avoid_: Common, lib, shared module
